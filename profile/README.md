## Overview
TextExpander for Mac turns short abbreviations into full pieces of text — email replies, addresses, code snippets, support responses — typed instantly wherever you're working. Instead of copying and pasting the same paragraph for the tenth time, you type a few characters and TextExpander fills in the rest, working system-wide across nearly any Mac app.

## Features
| Feature | What it does for you |
|---|---|
| Custom abbreviations | Turn a short string of characters into any snippet of text |
| Fill-in fields | Build snippets with blanks you complete at the moment of expansion |
| Cross-app expansion | Works inside email, browsers, chat apps, and most other Mac software |
| Snippet groups | Organize snippets by project, client, or workflow |
| Synced snippets | Keep the same snippet library available on every Mac you use |

## Installation
1. Download the TextExpander installer using the button above.

## Getting Started
1. Sign in with your TextExpander account, or create one during first launch.
2. Open the snippet editor and create your first abbreviation.
3. Try typing that abbreviation in any app to see it expand automatically.
